# pythonTasks
It's a repository for solving python problems

# Запуск тестов:
 "pip install -r 'requirements.txt'" для установки всех зависимостей

 "python main.py" для запуска и вывода результатов всех функций
 "pytest -q" — из директории для запуска проверки тестов

 "pytest -v" — (verbose mode) для более информативного запуска 
 проверки тестов
